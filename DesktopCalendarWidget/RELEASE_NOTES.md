## DesktopCalendarWidget 1.3.0

首次公开发布 Windows 桌面日历挂件，适用于 Windows 10 / 11 x64。

### 功能

- 按月显示公历、农历、今日高亮与干支年份。
- 支持每周单休、隔周单休（大小周）；以周一为界，设置本周单/双休后自动逐周推算并按实际休息日着色。
- 节假日与调休支持本地编辑和手动联网更新。
- 支持拖动、位置锁定、透明度和鼠标穿透。
- 提供日历应用图标，托盘常驻；挂件不占用任务栏按钮，双击托盘图标可切换显示/隐藏。
- 单实例运行，重复启动会通知已有实例显示挂件。

### 下载与使用

下载 `DesktopCalendarWidget-1.3.0-win-x64.msi`，双击安装。安装包包含 .NET 运行时，无需另行安装 SDK。

从桌面或开始菜单打开「桌面日历」，右键托盘图标进入设置或退出。`Ctrl+Alt+C` 切换鼠标穿透，`Ctrl+Alt+L` 切换位置锁定。

`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。GitHub 自动提供对应标签的源码压缩包。

### 使用说明与限制

- 内置仅 33 条基础节假日记录，不是完整年度放假调休安排。请使用手动更新或编辑功能，并以国务院公布的安排为准。
- 手动更新依赖第三方公开接口，断网时继续使用本地数据；更新会按日期合并，需留意已手动修改的数据。
- 安装包未做代码签名，Windows 可能提示未知发布者。
