## DesktopCalendarWidget 1.7.0

日程统一为一种类型：原先「课程」和「事件」是两份文件、两套编辑界面，现在合并为单一的日程模型，共七种类型 —— 课程、会议、出行、提醒、生日、考试、其他。每种有各自的颜色和图标，在日期格里一眼可辨。`schedules.json` 一次性替代 `courses.json` 和 `events.json`，旧文件留在原地不动；迁移时算不出具体时刻的课程标为「待定时刻」，既不算全天也永不显示为全天。课程原有的按周重复（起止周、单双周）保留在统一模型里。

新增侧边日程抽屉：点日历上的某一天，右侧展开当天的完整日程，130 毫秒动画。抽屉从日历旁边长出来，日历本身不会被遮挡；连续点不同的日期只换内容、窗口不会一次次变宽。抽屉在挂件紧贴屏幕右缘时会自动翻到左侧，此时关闭按钮依然可见。开着鼠标穿透时抽屉改由托盘菜单或标题栏的「⋯」进入。

抽屉关闭动作三种方式都可用：标题栏按钮、`Esc`、再次点同一天。挂件被拖动后再关抽屉不会弹回原位。

修复展开抽屉时日历宽度抖动：原先先加宽窗口、再钉住日历列，中间有一帧日历铺满整窗再被拽回。改为先钉列后改窗。

修复展开抽屉时日历高度抖动：底部日程条原本跟着内容变高变矮，有日程和没日程时高度不同，被上方的日历整块吸收。底部区域改为固定高度并自行滚动。

日历格子不再挤压：节日名和农历原本各占一行，五层内容加起来比格子还高，节日名会溢出到相邻行。两者合并成一行、节日优先，底部日程条回到 150 像素。

窗口默认高度从 820 提到 940：格子 81 像素（最坏情况 61 像素）放得下四层内容，底部日程条同时够看四条。旧配置里偏矮的窗口会自动补高，但只往上补 —— 手动调小过的窗口不会被撑回去；屏幕不够高时保持原样。

天气修正：「今天」显示实时气温而不是当日最高温。此前只请求了实时天气码没请求实况温度，早晚温差大时挂件上的数字能和窗外差出五六度（例如实况 30℃ 而当日最高 36℃）。未来日期仍显示最高/最低温度。悬停提示两种都显示并标注「当前」。附带修复 wttr.in 把实时观测挂到响应第一条（假定即今天）的问题，临近午夜或跨时区时会挂错格子。

按钮、菜单、勾选框重做：原先全局只有一个透明无边框的按钮样式，没有悬停和按下反馈，菜单是 WPF 默认外观，设置窗口里十来个勾选框也都是系统样式。现在统一为米色赭红调的一套样式，含悬停、按下、焦点和禁用四态；菜单有圆角和投影，勾选项左侧是赭红对勾。挂件上的按钮悬停时压半透明白而非黑色，压黑在壁纸上显脏。保存按钮原先把强调色硬编码成 `#B44837`，与主题画刷脱钩，现已改为主题引用。

日程类型名称跟随界面语言，中英文各自显示。

本地 MSI 可从 1.6.0 升级，用户数据与缓存保留；旧的 `courses.json` / `events.json` 不会被删除。


## DesktopCalendarWidget 1.6.0

新增课程表：设置里填学期开始日期与学期周数后，日历按「自然星期 + 起止周 + 单双周」推算当天课程。日期格最多显示两门课和 `+N`，悬停提示列出节次、教室与教师，标题显示当前学期周数，今日摘要和托盘提示显示当天课程数。课程可在设置里可视化编辑，也可直接改逐行 JSON。

新增上课前提醒：勾选后按 0–120 分钟提前通过托盘气泡通知，可跨午夜触发，已通知记录存盘去重，重启不会重复提醒。没有课程时不启动提醒轮询。

新增日程：托盘菜单或日期格右键可增删改指定日期的全天与定时事件，悬停显示时间、地点与备注。「在日历上显示日程」开关只控制显示，不删除数据。

课程与日程文件中的无效记录在启动时提示丢弃条数，并说明再次保存会真的删除；课程数据未改动时保存设置不再重写文件。

本地 MSI 可从 1.5.10 升级，用户数据与缓存保留。


## DesktopCalendarWidget 1.5.10

修复区县天气搜索：Open-Meteo 地理编码无区县结果时自动使用 Photon 备用地理编码，并支持「广州 天河区」等完整关键词及区县后缀变体。天气位置可从候选行政区中明确选择，并按选中坐标查询。

修复当天天气现象显示不准确：Open-Meteo 使用实时天气码显示当天状况，未来日期仍显示逐日预报；wttr.in 兜底读取当前状况，并用正午时段表示日预报，避免将午夜天气当作全天状况。

本地 MSI 可从 1.5.9 升级，用户数据与缓存保留。

修复天气、翻译、更新和设置交互中的回归问题。

- 小屏幕启动时按屏幕尺寸调整窗口，并将恢复的位置约束在虚拟屏幕范围。

## DesktopCalendarWidget 1.5.0

日历放大到能同时看清天气、温度、农历和节假日，翻译窗改小改清爽，并新增了自动检查新版本。

### 新增功能

- **自动检查更新**：启动后与之后每 12 小时查询一次本仓库的最新 Release。发现新版时弹窗显示版本号与安装包大小，可 下载 / 稍后 / 不再提示这个版本。
- **一键下载安装包**：确认后带进度下载 MSI（可取消），下载完成再询问是否立即安装；选择安装时程序退出并启动安装向导。安装包为当前用户级别，不弹 UAC、不重启电脑。
- 检查更新只访问 GitHub 公开发布接口，不上传任何个人数据或日历内容；设置里的「更新」区可关闭自动检查，也可随时「立即检查更新」，并显示当前版本。

### 界面调整

- **日历整体放大**：窗口 474×566 改为 640×820，日期、农历、节假日标记与星期表头字号各加两号，标题、导航按钮同步放大。
- **每格天气独立成行**：天气图标与「最高/最低温度」并排显示在一行，温度缺失时只显示图标或文字，不再和农历挤在一起。
- **翻译窗重排**：默认 500×396 的紧凑布局，方向标签、原文、译文分区显示，占位提示与字数统计替代原来的空白框，状态一行截断显示并可悬停看全文。

### 数据来源与限制

- 更新检查依赖 `api.github.com` 可访问，网络不通时后台检查静默跳过，可在设置里手动重试。
- 翻译与天气仍使用免费公开接口，**没有服务承诺**，可能随时失效或限流；输入内容会发送给第三方服务。
- 免费天气接口只提供未来 16 天预报，超出范围的日期不显示天气；断网时继续显示上一次拉到的数据。

### 下载与升级

下载 `DesktopCalendarWidget-1.5.0-win-x64.msi`，双击安装即可覆盖升级，配置与缓存保留。已在用 1.4.0 的用户也可以直接由程序内的「检查更新」完成升级。适用于 Windows 10/11 x64，包含 .NET 运行时。用户配置、节假日、天气缓存与翻译缓存保存在 `%LocalAppData%\DesktopCalendarWidget`。

附件 `SHA256SUMS.txt` 提供安装包校验值；源码可下载此标签的 ZIP / tar.gz。

### 测试

版本号统一写在工程文件的 `<Version>` 里，发布流程会校验标签与它一致。回归测试新增 Release 解析用例（安装包挑选、无安装包、畸形响应、版本号归一），与翻译、天气测试一起离线运行，自动发布前全部执行。
